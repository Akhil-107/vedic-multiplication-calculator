    How the Method Works

    1. Start with the rightmost digits and multiply vertically.
    2. Move through crosswise digit products, adding the products for each diagonal.
    3. Keep the units digit of each sum and carry the remaining value to the next diagonal.
    4. Continue until all diagonals and the final carry are processed.
    5. Compare the final answer with the standard product to verify correctness.

    Important: This is a teaching implementation of a vertical-and-crosswise multiplication pattern. It does not claim that the algorithm is always faster than built-in multiplication. Modern language runtimes and processors optimize arithmetic heavily.
